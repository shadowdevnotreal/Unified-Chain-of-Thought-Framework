## 📚 **Usage Examples**

### Example 1: Intelligent Agent Recommendation

```python
from orchestrator.recommender import AgentRecommender

recommender = AgentRecommender()

result = recommender.recommend(
    task_description="Refactor authentication module with OAuth2 support",
    context={"complexity": "high", "security_critical": True}
)

print(f"Complexity: {result.complexity.value}")
print(f"Estimated Time: {result.estimated_total_time}")
print(f"Success Probability: {result.success_probability * 100}%")
print(f"\nRecommended Workflow:")
for rec in result.recommended_chain:
    print(f"  {rec.priority}. {rec.agent_name} ({rec.intensity.value})")
    print(f"     Reason: {rec.reason}")
```

**Output:**
```
Complexity: high
Estimated Time: 45-60 minutes
Success Probability: 96.8%

Recommended Workflow:
  1. security-auditor (cot++)
     Reason: security critical task + 2 keyword matches
  2. code-perfection-system (cot+)
     Reason: 3 keyword matches + suitable complexity
  3. test-engineer (cot+)
     Reason: pairs well with code-perfection-system
```

### Example 2: Pattern Library Usage

```python
from patterns.pattern_library import PatternLibrary, Pattern, PatternCategory

library = PatternLibrary()

# Add a pattern
pattern = Pattern(
    id="PLM-AUTH-001",
    name="JWT Token Refresh Pattern",
    category=PatternCategory.AUTHENTICATION,
    difficulty=DifficultyLevel.MEDIUM,
    context="Implementing token refresh without user re-authentication",
    solution="Use sliding window with refresh token rotation...",
    code_template="// See templates/auth/jwt-refresh.js",
    tags=["jwt", "authentication", "security"]
)

library.add_pattern(pattern)

# Record successful usage
library.record_usage(
    pattern_id="PLM-AUTH-001",
    success=True,
    duration_seconds=1380,
    quality_score=9.8
)

# Search and reuse
results = library.search_patterns(query="authentication")
for p in results:
    print(f"{p.name}: used {p.times_used} times, {p.success_rate*100}% success")
```
